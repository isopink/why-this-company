# output-example — why-this-company 출력 예시 (확정 형식)

실제 실행 결과가 아니라 형식을 보여주는 예시다 (삼성전자 / 공정 직무 기준).
이 형식은 scripts/render.py 가 만든다. Solar 는 2단계·3단계 본문(angles.txt)만 쓴다.
아래 3단계 리포트는 작업 공간 루트에 저장되는 txt 파일의 내용이다.
채팅에는 이 전문을 붙이지 않고, 문서 맨 아래 '채팅 응답 예시'만 출력한다.
모든 수치는 verify.py 통과본만 사용한다. 이모지·내부 용어("미판정", "파싱" 등)는 쓰지 않는다.

---

삼성전자 / 공정 직무 — 지원동기 방향성 리포트

## 1단계 — 주목할 사항

```
[잘하고 있는 것]
연결 매출 3개년 연속 성장: 258조 9,355억 -> 300조 8,709억 -> 333조 6,059억
영업이익 43조 6,011억 (2025, 연결) — 전기 32조 7,260억 대비 큰 폭 개선
(영업이익이 감소한 회사는 이 블록이 아니라 [참고 수치]에 "전기 대비 감소 (판정 기준에
 없는 항목이라 문제로 세지 않음)"으로 표시된다 — render.py 가 자동으로 나눈다)

[그럼에도 주목할 사항]
주목 1. 원재료를 소수 거래처에 의존
   핵심 재료의 공급처가 소수로 지정되어 있습니다.
   - 모바일: AP 솔루션·카메라 모듈 -> Qualcomm, 삼성전기 등
   - 반도체: Chemical·Wafer -> 솔브레인, SILTRONIC 등
   - 디스플레이: FPCA·Cover Glass -> 비에이치, Apple 등
   공급처 한 곳의 수급·단가 변동이 곧바로 생산 라인에 영향을 주는 구조입니다.
   (판정: 소수 거래처 의존 — 주요 매입처 소수 지정 명시,
    K-IFRS 주요 고객 공시 취지 참조)

[확인 결과 특이사항 없음]
- 성장 정체: 해당 없음 — 매출이 2년 연속 감소하지 않음 (3개년 연속 성장)
- 지역 쏠림: 해당 없음 — 상위 지역 비중 합이 기준(70%) 이내
- 투자 확대: 해당 없음 — 연구개발 비중에 뚜렷한 상승 없음

[자동으로 읽지 못한 항목]
- 부문별 매출: 보고서의 표 형식이 회사마다 달라 자동으로 읽지 못했습니다.
  부문별 쏠림·급한 변화 여부는 원문에서 직접 확인해 주십시오:
  II. 사업의 내용 > 4. 매출 및 수주상황
  원문: https://dart.fss.or.kr/dsaf001/main.do?rcpNo=<rcpNo>
```

## 2단계 — 지원 직무와 닿는 지점

```
공정 직무 -> 주목 1(원재료 의존)

원재료가 소수 거래처에 묶여 있다는 것은, 공정 입장에서 "들어오는 재료의
편차를 통제할 수단이 회사 안에 있어야 한다"는 뜻입니다. 공정 직무가
이 문제에 기여할 수 있는 접점이 분명합니다.
```

## 3단계 — 사항별 "지원동기로 쓴다면" 방향성

```
주목 1. 원재료를 소수 거래처에 의존

이 사항을 지원동기로 쓴다면
  - 공정 조건을 표준화해 원재료 편차를 흡수하는 방향
  - 대체 소재 검증 데이터를 축적하는 방향
  - 입고 단계에서 품질 편차를 사전 감지하는 방향

구체화 참고 — KIPRIS 최근 3년 출원 키워드(반도체·소자·메모리)를 보면
공정·소자 쪽 연구가 활발하므로, "대체 소재 검증" 방향성은 반도체 소재
검증 쪽으로 좁혀 쓸 수 있습니다.

방향성의 선택은 지원자 본인의 몫입니다. 직접 고른 방향성이어야
"왜 그 방향이었는가"라는 질문에 답할 수 있습니다.

출처 — 사항: 사업보고서 원재료 및 생산설비 /
방향성: 매핑 테이블 [의존 × 공정·생산]

[출처]
사업보고서 (연결 기준, 제57기) — DART 원문: https://dart.fss.or.kr/dsaf001/main.do?rcpNo=<rcpNo>
  1번: II. 사업의 내용 > 3. 원재료 및 생산설비 (주요 원재료 현황)
KIPRIS 특허 검색 — 최근 3년 출원 80건 (분석 판단에는 사용하지 않음)

[판정 기준] (이번 리포트에 확인·적용된 것)
소수 거래처 의존: 주요 매입처가 소수로 명시된 경우 (K-IFRS 주요 고객 공시 취지 참조)
성장 정체: 매출이 2년 연속 감소한 경우
지역 쏠림: 상위 1~2개 지역 비중 합이 70% 이상인 경우
  (공정거래법 시장지배력 추정 기준 참조)
투자 확대: 연구개발 비중이 전년보다 오른 경우

[특허 동향]
최근 3년 출원 80건 — 키워드: 반도체, 제어, 메모리, 전자, 소자
(KIPRIS, 분석 판단에는 미사용)

[더 볼 것] 지속가능경영보고서 (자율공시) — 별도 공시라 접수번호가 다릅니다.
DART(https://dart.fss.or.kr)에서 회사명 + "지속가능경영보고서"로 검색해 주십시오.

[저장] why-this-company_삼성전자_공정_20260830.txt (작업 공간 루트 — 폴더 아이콘에서 열림)
```

## 채팅 응답 예시 (전문은 파일에만 — 채팅은 이게 전부)

```
삼성전자 / 공정 직무 — 리포트를 완성했습니다.

주목할 사항 1건
- 원재료를 소수 거래처에 의존 (Chemical·Wafer -> 솔브레인, SILTRONIC 등)

확인했지만 해당 없음: 성장 정체, 투자 확대
원문 확인 필요: 부문별 매출, 지역별 매출
지원동기 방향성 3개 제시

리포트 열기: <share_file이 돌려준 다운로드 링크>
[저장] why-this-company_삼성전자_공정_20260830.txt (작업 공간 루트 — 폴더 아이콘에서 열림)
```

채팅 응답은 [저장] 줄이 마지막이다. 뒤에 제안이나 인사를 붙이지 않는다.

## 규칙 요약

- 문장을 쓰는 건 사용자다. 방향성을 여러 개 주는 이유는 고르게 하기 위해서다.
- 모든 수치에 판정 근거와 출처(rcpNo 링크)를 붙인다. 금액은 "3조 5,143억"처럼 조+억.
- 저장 파일은 제목 첫 줄부터 [저장] 줄까지만. 작업 메모·명령어를 파일 뒤에 붙이지 않는다.
- 판정 결과는 judge 출력을 그대로 옮긴다. 미판정은 [특이사항 없음], 판정 불가는
  [읽지 못한 항목] — 한 유형을 두 곳에 쓰지 않고, 기준을 다시 해석하지 않는다.
- 검토했으나 해당하지 않는 유형도 [확인 결과 특이사항 없음]으로 보여준다 — 숨기지 않는다.
- 읽지 못한 항목은 [자동으로 읽지 못한 항목]에서 원문 확인 경로로 안내한다.
- 링크는 자리표시 문구("원문 링크", "(링크)")가 아니라 실제 URL 전체를 쓴다.
  <rcpNo>는 실행 시 실제 접수번호로 치환한다. URL을 모르는 문서는
  링크가 있는 척하지 않고 DART 검색 경로를 안내한다.
