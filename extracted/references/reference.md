# reference — why-this-company 판정 기준과 방향성 매핑

이 문서는 스킬이 방향성을 제시할 때 참조하는 유일한 지식 원천이다.
여기 없는 방향성은 만들지 않는다.

## 1. 문제 유형 판정 표 (judge.py가 코드로 수행)

| 유형 | 판정 조건 |
|---|---|
| 편중 | 상위 1-2개 항목 비중 합 ≥ 70% (항목 2개 이하면 1위만 판정) |
| 급변(확대/축소) | 전년 대비 비중 ±10%p 이상 |
| 의존 | 매입처·고객이 소수 지정으로 명시 |
| 정체/역성장 | 매출 2년 연속 감소 |
| 투자 확대 | R&D 비중 상승 또는 신규 시설투자 정황 |
| 수익성 악화 | 영업이익 전년 대비 10% 이상 감소 |

## 2. 판정 근거 우선순위 — "왜 70%인가요?"에 답하기 위해

| 순위 | 기준 유형 | 예시 |
|---|---|---|
| 1 | 회사가 사업보고서에 직접 쓴 위험요소 | 위험 서술과 계산 결과 일치 → 반박 불가 |
| 2 | 회계기준·법령 차용 | K-IFRS 1108호(단일 고객 10% 공시 의무), 공정거래법 시장지배적 추정(1사 50%, 3사 75%) |
| 3 | 자사 과거 대비 추이 | "2년 연속 감소" — 임계값 논쟁 없음 |
| 4 | 절대 임계값(초기값) | 편중 70%, 급변 ±10%p — 테스트로 조정 |

출력의 모든 판정에 근거를 함께 표기한다.

## 3. 직무 키워드 사전 (6계열)

| 입력 직무 키워드 | 계열 |
|---|---|
| 공정, 생산, 품질, 설비, 제조 | 공정·생산 |
| R&D, 연구, 개발(소재·소자·공법), 분석 | R&D |
| 기획, 전략, PM, 사업개발, 상품기획 | 기획·전략 |
| SW, 데이터, 개발자, IT, 시스템 | 개발(SW·데이터) |
| 영업, 세일즈, BD, 마케팅, 해외영업 | 영업·마케팅 |
| 재무, 회계, 구매, SCM, 자금 | 재무·구매(SCM) |

6계열 밖(HR·디자인 등)은 공시 기반 방향성 도출이 어려움을 명시하고
문제 목록까지만 제공한다.

## 4. 유형 × 직무 매핑 테이블 (42칸 — 팀 검수 반영본 + 수익성 악화 행 추가)

Solar는 해당 칸의 골격만 사용하고, 회사의 실제 숫자로 구체화만 한다.
수위 원칙: 신입 관점 — 수립·확보·조달이 아니라 분석·검증·지원·모니터링.

| 유형 | 공정·생산 | R&D | 기획·전략 | 개발(SW·데이터) | 영업·마케팅 | 재무·구매(SCM) |

| 편중 | 수출 지역별 규격·규제 대응 공정 표준화 | 신규 시장·제품군 겨냥 기술 다변화 연구 | 신규 시장 진입 검토 지원, 신규 고객군·지역 분석 | 다지역 규격·인증 데이터 관리 시스템 | 신규 지역·고객군 개척 영업 지원, 채널 다변화 | 환위험 모니터링·헤지 효과 분석, 지역별 매출채권 리스크 분석 |

## 5. Solar 구체화 규칙

- 입력: 문제의 실제 숫자 + 해당 칸의 방향성 골격 2-3개
- 작업: 골격을 이 회사의 숫자·고유명사로 구체화만
- 금지: 테이블 밖 방향성 창작, 숫자 변형, 자소서 문장 완성
- 방향성 출처는 "매핑 테이블 [유형 × 계열]" 좌표로 표기
