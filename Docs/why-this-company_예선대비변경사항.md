48팀 402 Not Found (이석민, 김나연, 김동규) | 예선 스킬을 결선 서비스로 옮기며 달라진 점

## 0. 문서 범위
| 항목 | 내용 |
|---|---|
| 예선 기준 | 예선 제출 스킬 why-this-company (SKILL.md, 스크립트 5종, references) |
| 결선 기준 | https://github.com/isopink/why-this-company (기준 커밋: 제출 직전 커밋 해시) |
| 목적 | 예선 스킬이 결선 서비스에서 어떻게 쓰이는지, 달라진 부분이 무엇인지 기록 |

## 1. 요약
결선 서비스는 예선 스킬을 그대로 가져와 웹에서 쓸 수 있게 감싼 형태다. 공시를 읽고 주목할 사항을 판정하고, 매핑 테이블 안에서 방향성을 만들고, 숫자를 원본과 다시 대조하는 핵심 흐름은 예선과 같다.

달라진 것은 크게 세 가지다.
- 채팅 대신 웹 화면에서 실행되도록 연결한 것
- 방향성을 질문으로 보여주고 답을 적게 한 것
- 스킬 바깥에 IR 자료 분석을 붙인 것

## 2. 그대로 유지한 것
| 항목 | 내용 |
|---|---|
| 판정 로직 | judge.py 수정 없음. 판정은 코드가 하고 LLM은 관여하지 않음 |
| 검증 로직 | verify.py 수정 없음 (금액 ±1억, 비율 ±0.5%p) |
| 매핑 테이블 | references/reference.md 수정 없음. 7행 x 직무 6계열 = 42칸, 테이블 밖 방향성은 만들지 않음 |
| 처리 순서 | 공시 수집, 판정, 방향성 작성(Solar Pro 4), 리포트 생성, 수치 재대조 |
| 공시 범위 | 최신 사업보고서, 연결 우선(없으면 별도), 재무 3개년, 사업의 내용 4개 항목 |
| 직무 분류 | 공정·생산, R&D, 기획·전략, 개발(SW·데이터), 영업·마케팅, 재무·구매(SCM) |
| 표현 규칙 | "주목할 사항" 용어, 조·억 병기, 내부 용어 비노출, DART 원문 링크 |
| 기본 원칙 | 자소서 대필 안 함, 경험을 지어내지 않음, 공시에 없는 숫자를 만들지 않음, 원인 해석·기업 평가·주가 전망 안 함 |
| 개인정보 | 이름, 학교, 연락처, 학점, 경력을 받지 않음 |

## 3. 서비스로 옮기며 조정한 부분
| 항목 | 예선 | 결선 |
|---|---|---|
| 실행 환경 | 채팅 에이전트가 스크립트 실행 | 서버(`/api/jobs`)가 같은 스크립트를 같은 순서로 실행 |
| 입력 | 채팅 문장에서 회사·직무를 읽고, 빠지면 되물음 | 화면에서 직무와 회사를 선택 (회사 검색은 상장사만) |
| 출력 | 리포트 txt 파일 | 같은 리포트 내용을 화면 카드로 표시 |
| 방향성 제시 | 방향성 목록 | 같은 방향성을 질문 형태로 보여주고 답을 적게 함. 답은 브라우저에 저장하고 txt로 내려받음 |
| 검증 후 처리 | 에이전트가 문장을 고쳐 다시 실행 | 서버가 자동 처리. 방향성 숫자가 걸리면 방향성을 빼고 다시 리포트 생성 |
| API 키 | 타임리 환경변수 | Render 서버 환경변수 |

## 4. 스크립트 수정
서버에서 실행하기 위해 두 파일을 조금 고쳤고, 판정·검증 결과에 영향을 주는 수정은 없다.

| 파일 | 수정 내용 |
|---|---|
| scripts/dart_client.py | 서버의 `.env`에서 API 키를 읽는 부분 추가. 회사코드 조회 방식을 서버 메모리에 맞게 가볍게 바꿈 |
| scripts/render.py | 방향성이 없을 때 멈추지 않고 리포트를 만들도록 조정. 방향성 항목 길이 제한 완화(95자에서 140자) |
| scripts/company_search.py | 화면의 회사 검색용으로 추가. 기존 dart_client의 조회 기능을 그대로 사용 |

## 5. 스킬 바깥에 추가한 것
스킬 파일은 건드리지 않고 서버에 별도 모듈로 붙였다.

- IR 자료 분석(`backend/app/api/ir.py`): 사용자가 올린 IR PDF에서 회사가 밝힌 향후 방향을 찾아 리포트에 따로 보여주고 질문을 만든다. 예선 매핑 테이블과 같은 방식의 IR 매핑표(주제 6개 x 직무 6계열)를 쓰고, 인용문과 숫자를 원문과 대조한다.
- 웹 화면(`backend/app/static/index.html`): 탐색, 리포트, 질문, 답변 모아보기 화면.
