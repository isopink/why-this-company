# why-this-company 미니 PRD

48팀 402 Not Found (이석민, 김나연, 김동규) | 결선 MVP

## 1. 한 줄 정의
산업 경험이 부족한 신입 취준생이 회사와 직무를 고르면, 사업보고서(DART)에서 지난 실적을, IR 자료에서 회사의 향후 방향을 찾아 직무별 질문으로 만들어 주는 서비스. 사용자는 질문에 직접 답하면서 지원동기와 면접 답변의 근거를 정리한다. 회사 한 곳을 준비하는 데 약 7시간 걸리던 일을 1시간 내외로 줄인다.

## 2. 타깃 사용자
하반기 공채를 준비하는 학사 신입 취준생.

- 지원하는 산업 쪽 경험이 거의 없어서 "왜 이 회사인가"에 쓸 근거가 없음
- 한 시즌에 여러 회사에 지원함. 홈페이지나 뉴스를 보고 쓰다 보니 회사 이름만 바꾸면 어디든 들어가는 문장이 됨
- 회사 한 곳의 지원동기 근거를 찾고 정리하는 데 약 7시간이 걸려, 여러 곳에 지원하면 준비 시간이 크게 불어남
- 사업보고서나 IR 자료를 열어 봐도 어디를 봐야 할지 몰라서 결국 닫음
- 숫자가 틀리거나 출처가 애매하면 다시 쓰지 않음

공시 문서를 읽는 방법을 모르는 것이 가장 큰 장벽이라고 봤다. 로그인이나 비용 없이 링크만 열면 바로 쓸 수 있게 했다.

제외 대상: 사업보고서를 내지 않는 회사의 지원자. HR, 디자인처럼 공시와 연결이 어려운 직무는 주목할 사항까지만 보여준다.

## 3. 문제
지원동기에 쓸 재료는 공시(지난 실적)와 IR(회사가 밝힌 계획)에 이미 있다. 그런데 어디를 봐야 하는지, 내 직무와 어떻게 연결하는지 모르니 결국 일반론으로 끝난다. AI로 문장을 받으면 빨리 쓸 수는 있지만 근거가 없어서 꼬리질문에 대답하지 못한다.

직접 근거를 찾으면 공시와 IR을 뒤지고 내 직무와 연결하는 데 회사 한 곳당 약 7시간이 든다(팀 자체 측정). 시간이 부족하니 근거 조사를 건너뛰고 일반론이나 AI 문장에 기대게 된다.

- 구직자 1,226명 대상 조사에서 가장 어려운 자소서 문항 1위가 지원동기(28.6%) (인크루트·알바콜, 2021)
- Z세대 구직자 1,592명 중 86%가 AI 툴을 써 봤고, 그중 51%가 자소서·이력서 작성에 사용 (진학사 캐치, 2025.07)
- 매출 상위 500대 기업(315곳 응답) 중 64.1%가 챗GPT로 쓴 자소서를 부정적으로 봄. 확인되면 감점 42.2%, 불합격 23.2% (고용노동부·한국고용정보원, 2023년 하반기 기업 채용동향조사)
- "DART를 보라는데 한도 끝도 없고 어디까지 뭘 어떻게 해야 하나요. 시험 범위 없는 시험공부 하는 기분입니다" (한국경제, 기사 제목·날짜)

## 4. 트리거
사용자가 링크로 직접 들어온다. 알림이나 푸시는 보내지 않는다.

- 채용 공고를 막 확인했는데 이 회사에 대해 뭘 찾아봐야 할지 모를 때
- 지원동기를 쓰다가 내용이 뻔해질 때
- 면접 전에 서류에 적은 숫자와 회사 계획의 출처를 다시 확인하고, 예상 꼬리질문을 준비할 때

9~10월 하반기 서류 기간에 가장 많이 쓸 것으로 예상한다.

## 5. 핵심 기능
### P0 (결선 데모 필수, 최대 4개)
| # | 기능 | 내용 |
|---|---|---|
| 1 | 회사·직무 선택 (01 탐색, IR 자료) | 지구본에서 직무·회사 노드를 누르거나, 오른쪽 패널에서 직무를 고르고 회사명·종목코드로 검색. 다음 화면에서 원하면 해당 회사 IR 자료 PDF(실적발표, 기업설명회, 지속가능경영보고서 등)를 올림 |
| 2 | 공시·IR 분석 (02 준비) | 공시: DART 수집, 규칙 기반 판정, Solar Pro 4로 방향성 작성, 수치 재대조. IR: PDF를 쪽별 텍스트로 바꿔 서버로 보내고 Solar Pro 4로 비전·전망·기술 동향 추출, 인용문·숫자·매핑·질문 형식 검사. 둘 다 끝나면 리포트로 이동(IR은 최대 150초 대기) |
| 3 | 리포트와 질문 (03 리포트, 04 질문) | 리포트는 "지난 실적(공시)"과 "회사가 밝힌 방향(IR)"으로 나눠서 수치, 근거, 원문 위치를 보여줌. 질문은 3~7개로 공시 질문과 IR 질문(최대 3개)을 번갈아 배치. "왜 우리 회사에 지원했나요?"는 항상 넣고, 3개가 안 되면 직무 선택 질문으로 채움. IR 분석이 실패하면 자료를 직접 읽고 답하는 고정 질문 1개를 넣음. 질문마다 꼬리질문 1개 |
| 4 | 답변 모아보기 (05 모아보기) | 답은 브라우저에 자동 저장. 질문과 답을 한 장으로 모아 txt로 내려받기 |

### P1
- 근거 카드: 한 사항의 숫자, 원문 위치, 판정 기준을 카드 하나로 정리
- DOCX, TXT 형식 IR 자료 지원

### 화면 구성과 화면별 기능
모든 화면 상단에는 진행 단계 표시(01 탐색, 02 준비, 03 리포트, 04 질문, 05 모아보기)와 "내 기록", "새로 시작" 버튼이 있다.

| 화면 | 주요 기능 |
|---|---|
| 시작 | 서비스 소개("많은 회사 중, 왜 이 회사인가요?"), "나의 이유 찾기" 버튼으로 탐색 시작 |
| 01 탐색 | 3D 지구본에 직무 6개와 예시 기업을 노드로 표시. 드래그·방향키로 회전, 확대·축소, 시점 초기화, 회전 멈춤. 직무 노드나 오른쪽 패널 버튼으로 직무 선택 후, 연결된 회사 노드를 누르거나 회사명·종목코드로 검색. "다른 직무 고르기"로 되돌아가기 |
| IR 자료 (선택) | 선택한 회사·직무 표시, IR 보고서를 찾는 곳 안내. PDF를 끌어 놓거나 파일 선택(1개, 최대 20MB), 파일 바꾸기·빼기. "IR 자료와 함께 분석하기" 또는 "IR 없이 분석하기" 선택 |
| 02 준비 | 리포트와 질문 사용법 안내(수치와 원문 위치 제공, 답변 자동 저장, 모범답안 없음). 분석 진행 표시, 끝나면 "리포트 보기" 버튼 활성화 |
| 03 리포트 | 잘하고 있는 것, 주목할 사항 카드(수치, 판정 기준, DART 원문 링크), 확인 결과 특이사항 없음, 회사가 밝힌 방향(IR). "질문 받기"로 이동 |
| 04 질문 | 질문 번호와 진행 막대. 질문마다 근거(공시 수치 또는 IR 인용문과 쪽수), 꼬리질문, 답 입력칸(글자 수, 저장 상태 표시). 이전·다음 이동, 판정 기준 펼쳐 보기 |
| 05 모아보기 | 질문별로 내가 쓴 답을 모아 보여주고 답마다 수정 가능. "답변 내려받기"(txt), 첫 질문부터 다시 보기, 리포트 다시 보기. 질문 근거와 저장 방식 안내 |
| 내 기록 | 지금까지 작성한 기록 목록(회사, 직무, 날짜, 답변 수). 기록을 눌러 이어서 작성, 기록별 삭제, 전체 삭제 |

## 9. 데이터 규칙
**공시와 IR 구분**
- 과거 내용은 DART 공시(확인된 실적)로만, 미래 내용은 IR 자료(회사가 밝힌 계획)로만 채움
- 두 출처를 한 문장에 섞지 않고 화면에서도 영역을 나눔
- IR 내용으로 공시 판정을 바꾸지 않고, 공시 숫자로 IR 계획을 평가하지 않음

**출처 표기**
- 공시: 사업연도, 접수번호(원문 링크), 연결/별도 기준
- IR: PDF 쪽 순서 기준 쪽수(p.N). 발표일과 URL은 추측해서 넣지 않음
- 재무는 연결(CFS)을 우선 사용. 연결이 없으면 별도(OFS)를 쓰고 "별도(연결 없음)"로 표기
- 읽지 못한 표나 값은 "확인 불가"와 원문 위치로 안내. IR 자료에 없는 항목은 "자료 내 미언급"

**공시 판정과 검증**
- 판정은 코드가 수행하고, Solar Pro 4는 매핑 테이블(7행 x 직무 6계열 = 42칸, 급변은 확대/축소 2행) 안에서 실제 숫자로 문장만 작성
- 판정 기준
  - 편중: 부문·지역 매출 비중 상위 2개 합 70% 이상 (팀이 정한 기준)
  - 급변: 비중이 전년 대비 ±10%p 이상 변동
  - 의존: 원재료 항목에 매입처가 소수로 기재됨
  - 정체·역성장: 매출 2년 연속 감소
  - 수익성 악화: 전년 흑자에서 영업이익 10% 이상 감소 (적자 전환 포함)
  - 투자 확대: R&D 비중 상승 또는 시설투자·증설 언급
- 표를 제대로 읽지 못하면 판정하지 않음
- 리포트의 금액과 비율은 원본 데이터와 다시 대조 (금액 ±1억, 비율 ±0.5%p)
- Solar가 쓴 방향성 문장의 숫자가 대조에서 걸리면 방향성을 빼고 판정 결과만으로 리포트를 다시 만듦

**IR 분석과 검증**
- Solar Pro 4는 IR 본문의 비전, 전망, 기술 동향을 그대로 옮기기만 하고 평가나 예측을 덧붙이지 않음
- 질문은 아래 IR 매핑표에서 선택한 직무 칸 안에서만 만들고, 최대 3개. 여섯 주제에 해당하지 않는 내용으로는 질문을 만들지 않음

- 질문 유형은 지원 동기, 사업 이해, 기여 방안, 적용 아이디어 4가지. 금액·비율 수치나 1인칭 표현이 들어가거나 물음표로 끝나지 않는 질문은 버림
- 서버에서 확인하는 것: 인용문이 표시한 쪽에 실제로 있는지(공백 무시하고 비교), 핵심 내용의 숫자가 그 쪽에 있는지, 매핑 위치가 선택 직무 칸인지. 통과한 항목만 화면에 보냄
- 분석에 실패하면 IR 영역만 비우고 나머지 진행은 그대로

**IR 자료 처리**
- PDF 원본은 서버로 보내지 않음. 브라우저에서 쪽별 텍스트만 추출해 `/api/ir-questions`로 전송하고, 서버는 분석 후 저장하지 않음
- 본문 내용으로 IR 자료인지 먼저 확인하고, 아니면 분석하지 않음
- 문서 안에 적힌 지시문은 따르지 않고 내용으로만 취급
- 너무 긴 파일에 대비해 40만 자 상한을 둠

**키와 개인정보**
- API 키는 서버 환경변수에만 둠. 화면 소스와 API 응답에 키나 요청 주소를 넣지 않고, 사용자에게 키를 받지 않음
- 공개 공시 조회 권한만 사용. 이름, 학교, 연락처 같은 개인정보는 받지 않음

**화면 안내 문구**
- 탐색 화면의 회사 목록은 예시이며 실시간 채용 현황이 아님
- IR 영역은 회사 측 주장임
- 리포트는 취업 준비용 참고 자료이며 투자 판단 자료가 아님. 정정 공시가 나오면 재무 수치가 바뀔 수 있음

## 10. 성공 기준
| 항목 | 기준 |
|---|---|
| 시크릿 창 | 로그인이나 저장값이 없는 시크릿 창에서 공개 URL에 처음 들어가도 안내가 뜨고, IR 자료 없이 01 탐색부터 05 모아보기까지 진행됨 |
| 완주 (공시) | 탐색 화면의 22개 기업 모두 05까지 끊기지 않고 진행 |
| 완주 (IR) | 실제 IR PDF (IR 테스트 기업 수)개로 "회사가 밝힌 방향" 영역과 IR 질문이 표시됨 |
| 정확성 | Solar가 쓴 문장에서 대조 실패 수치 0건. IR 인용문과 숫자가 모두 표시한 쪽에서 확인됨 |
| 재현성 | 같은 회사·직무로 3번 실행하면 공시 주목할 사항이 같게 나옴 |
| 부분 실패 | Solar 호출이나 IR 분석이 실패해도 공시 주목할 사항과 수치는 정상 표시 |
| 예외 안내 | 없는 회사명이나 사업보고서가 없는 회사를 넣으면 오류 화면 대신 이유와 대안을 안내. IR이 아닌 PDF를 올리거나 분석이 실패해도 멈추지 않고 공시 흐름은 끝까지 진행 |
| 키 노출 | 화면 소스와 API 응답에 키 값 없음 |
| 응답 시간 | IR 자료 없이 회사·직무를 고른 뒤 03 리포트가 뜨기까지 120초 이내. IR 자료를 올린 경우 IR 분석 대기는 최대 150초이며, 넘기면 공시 리포트를 먼저 표시 |
| 유지 | 제출 후 심사가 끝날 때까지 공개 URL 접속 가능 |

## 11. 제외 범위
- 자소서 문장 대필, 모범답안 제공
- 사용자 경험을 묻거나 지어내는 것
- 기업 평가, 지원 여부 추천, 주가 전망 (IR의 전망은 회사 발표 내용을 옮기기만 함)
- 숫자의 원인 해석, 과거 공시와 IR 계획 사이의 인과 추론
- 공시·IR에 없는 숫자 생성
- IR 자료 자동 수집, 반기·분기보고서, 웹 검색으로 찾는 최신 동향 (지속가능경영보고서·ESG 보고서는 사용자가 직접 올린 경우에만 분석)
- 채용공고 키워드 반영, 경쟁사 비교, 특허(KIPRIS) 데이터
- 로그인, 서버 저장, 알림
